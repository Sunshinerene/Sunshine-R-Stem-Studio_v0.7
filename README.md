Sunshine@R Stem DAW Studio - Update

Dieses Update enthaelt die aktualisierte www/index.html.
GitHub: Datei im Repository unter www/index.html ersetzen.

Enthaltene erste Ausbaustufe:
- .srdaw Projektdatei speichern und oeffnen, inklusive importierter Audio-Buffers
- Instrumentenauswahl je MIDI-Spur (Supersaw, Pluck, Acid 303, Bell, Sub Bass)
- Native Web-Audio Insert-Effekte je Spur: EQ, Compressor, Filter, Delay, Distortion

Hinweis: Das ist noch kein VST/VST3-Host. Externe VST-Plugins und SoundFont/SF2/SF3-Import sind noch nicht implementiert.
Die automatische Wiederherstellung nach App-Neustart und eine vollwertige Plugin-Oberflaeche sind weitere Ausbauschritte.
